# PSL Analytics — Project Memory

## 1. Project Identity
**Project:** PSL Analytics & Match Intelligence Platform

The project combines cricket data engineering, advanced analytics, custom metrics, machine learning, and an interactive dashboard.

## 2. Core Philosophy
The goal is not merely to display cricket statistics.

The goal is to derive meaningful insights and decisions from cricket data.

## 5. Signature Metric
The PSL Impact Score is the project's primary differentiator.

It should answer:

> Who contributed the most relative to the difficulty and context of their performance?

## 6. Context Principle

```text
Raw Performance ≠ True Impact
```

The same number of runs or wickets can have different value depending on match context.

## 7. ML Philosophy
Machine learning should answer a real analytical question, not simply exist for the appearance of AI.

Examples:
- Expected Runs → How much should the batter have scored?
- Win Probability → Who is more likely to win now?
- Player Similarity → Which players have similar profiles?
- Turning Point → Which events changed the match?

## 8. Explainability
Predictions should be accompanied by major contributing factors whenever practical.

Example:

```text
Team A Win Probability: 73%

Positive factors:
+ Strong batting position
+ Low required RR
+ 7 wickets remaining

Negative factors:
- Opponent has strong death bowling
```

## 12. Golden Rule

For every feature ask:

1. What problem does it solve?
2. What data supports it?
3. What decision or insight does it produce?

If a feature cannot answer these questions, it does not need to be added.
